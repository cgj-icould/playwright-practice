# 自动化测试项目合集

这是一个综合的自动化测试代码库，包含以下两个核心项目：

## 1. UI 自动化测试框架 (Playwright + TypeScript)
- 目录：`playwright-ui-framework/`
- 架构：采用 POM (Page Object Model) 设计模式
- 技术栈：TypeScript, Playwright, Node.js
- 亮点：支持组件复用、断言校验、HTML 可视化报告

## 2. 接口自动化测试框架 (Python + Pytest)
- 目录：`api-test-framework/`
- 架构：Core / Api / Tests 三层分层架构
- 技术栈：Python, Pytest, Requests, PyYAML
- 亮点：支持 YAML 数据驱动 (DDT)，快速执行
